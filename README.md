# Recipe Organizer

A personal collection for storing cooking recipes.

## Features

- Recipe names
- Ingredient lists
- Cooking instructions
- Local storage

## How to Use

Enter the recipe name, ingredients and instructions.

## Technologies

- HTML
- CSS
- JavaScript

## Running Locally

Open `index.html` in a modern web browser.
